## Downloads

| Platform | File | How to install |
| --- | --- | --- |
| Windows 10/11 (x64) | `EyeTimer-windows-x64-setup.exe` | Run it. It installs for your user only, without admin rights. To update, run a newer installer. |
| macOS 12+ (Apple silicon and Intel) | `EyeTimer-macos.dmg` | Open it and drag **Eye Timer** to Applications (or anywhere, e.g. `~/Applications`). To update, replace the app. |
| Ubuntu 24.04+ / Debian 13+ (x64) | `EyeTimer-linux-amd64.deb` | Double-click it, or run `sudo apt install ./EyeTimer-linux-amd64.deb`. To update, install a newer one. |

Installing, updating and uninstalling never touch your settings.

**First launch warnings.** The builds are not code-signed yet:

- **Windows:** SmartScreen may say "Windows protected your PC". Choose **More info** → **Run anyway**.
- **macOS:** Gatekeeper may say the app "cannot be opened". Right-click (or Control-click) the app, choose **Open**, then **Open** again. On macOS 15 and later, use **System Settings → Privacy & Security → Open Anyway**.
- **Linux:** installing a `.deb` asks for your password, as every Debian package does.

Checksums for every file are in `SHA256SUMS.txt`.
